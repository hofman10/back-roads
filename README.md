# 🌍 Backroads Tour Company

A modern, fully responsive travel company landing page built with HTML5, CSS3 (Flexbox), and vanilla JavaScript. This project demonstrates clean code architecture, responsive design principles, and modern frontend development practices.

## 🚀 Live Demo

[View Live Demo](https://nikola-bijelic-example-3.netlify.app/)

## ✨ Features

### Core Functionality

- **Responsive Navigation**: Mobile-first navigation with hamburger menu toggle
- **Smooth Scroll**: Custom JavaScript implementation for smooth section navigation
- **Dynamic Content**: Tour cards with pricing and destination information
- **Newsletter Signup**: Email subscription form for user engagement
- **Interactive Gallery**: Image gallery with hover effects and search icons
- **Social Media Integration**: Links to social platforms with Font Awesome icons

### UI/UX Highlights

- Clean, modern design with consistent color scheme
- Accessible navigation with semantic HTML
- Intuitive user interface with clear call-to-action buttons
- Professional typography and spacing
- Optimized images for web performance

## 🛠️ Tech Stack

**Frontend:**

- HTML5 (Semantic markup)
- CSS3 (Flexbox, CSS Grid, Custom Properties)
- Vanilla JavaScript (ES6+)

**Libraries & Tools:**

- [Font Awesome 5.12.1](https://fontawesome.com/) - Icon library
- [Google Fonts (Lato)](https://fonts.google.com/) - Typography
- Git & GitHub - Version control

- **DOM Manipulation**: Event listeners for interactive elements

## 🏁 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- VS Code with Live Server extension (recommended)

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/yourusername/backroads-tour-company.git
   ```

2. **Open in VS Code**
   - Open the project folder in VS Code
   - Right-click on `index.html`
   - Select "Open with Live Server"

   _Or simply open `index.html` directly in your browser_

## 📱 Responsive Design

The project implements a mobile-first responsive design approach:

- **Mobile** (< 768px): Stacked layout, hamburger menu
- **Tablet** (768px - 1024px): Adjusted grid layouts, expanded navigation
- **Desktop** (> 1024px): Full navigation bar, multi-column layouts
